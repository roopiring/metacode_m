# 데이터엔지니어링 7기 · 7주차 업무 자동화

- 이름: 김병필
- 기수: 데이터엔지니어링 7기

Apache Airflow, Apache Spark, AWS S3를 연결해 데이터 처리 워크플로를 구성하는 과제 프로젝트입니다.

## 문항 구성

- Q3: Docker Compose 기반 Airflow 환경과 기본 DAG
- Q4: Spark 클러스터와 WordCount 작업
- Q5~Q9: Airflow 확장, XCom, Backfill, S3, 주간 파이프라인

문항별 구현 내용과 실행 방법은 작업이 진행될 때 갱신합니다.

## 실습 환경

김병필은 Docker Compose 환경에서 Airflow와 Spark 서비스를 함께 실행했습니다.

## 회고

데이터엔지니어링 7기 실습을 통해 작업 의존성과 재시도 흐름을 익혔습니다.
